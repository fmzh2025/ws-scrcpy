# 手机屏幕适配

移动端始终等比、完整显示云手机，旧版保存的拉伸偏好不再生效。复用现有悬浮控制菜单，不增加常驻工具栏。

## 使用

1. 在手机 Safari 打开云手机，保持竖屏、网页缩放为100%，收起手机键盘，等待浏览器工具栏稳定。
2. 点击悬浮 `⋯`，展开 **More**，点击 **适配当前手机**。
3. 等待画面自动重新连接后使用，在菜单可看到“已保存适配”。切换期间已有触点会抬起，并暂停新触控；新的屏幕信息和已解码画面匹配后恢复。
4. 日常刷新沿用保存的云手机尺寸；换手机或想适配另一种常用浏览器状态时，再点一次。
5. **恢复原始屏幕** 还原首次适配前记录的尺寸和DPI覆盖值，并清除保存的默认配置。

Safari地址栏、键盘和横竖屏变化只触发H5等比缩放，不反复改变Android分辨率。高度不足时宽度也会缩小，保证完整显示。剩余区域为黑色，不向云手机发送该区域触点。云手机内的列表仍按应用自身方式滑动。

## 配置和实现

- 读取实际 `visualViewport` 并扣除安全区，保留16 CSS像素高度余量。
- 保留当前云手机逻辑宽度和DPI，高度按网页比例计算并向下对齐16像素。例：1344宽、402×639网页区域对应1344×2080，显示约402×622。
- 配置按云手机UDID保存在服务器 `~/.config/ws-scrcpy/display-profiles/`；文件名为UDID的SHA-256，目录0700、JSON文件0600。可通过服务环境变量 `WS_SCRCPY_DISPLAY_PROFILE_DIR` 更换目录，不能放入静态资源目录。
- 保存原始配置后才修改Android；执行串行化，并读取 `wm size` / `wm density` 确认。应用或保存失败会尝试恢复操作前配置。进程重启、设备重新连接时检查保存的配置，必要时重新应用。
- `GET ./api/display-profile?udid=...` 返回实际状态和已保存尺寸。`POST ./api/display-profile` 接受同源JSON：`{udid,operation:"adapt",viewport:{width,height}}` 或 `{udid,operation:"restore"}`。接口复用现有设备控制权限范围，不需要开启ADB TCP访问，也不接受任意Shell命令。
- 同一台云手机的电脑及其他观看端会同步看到新布局。其他手机打开网页不会自动覆盖配置。
- 不支持在横屏、明显的软键盘缩小区域或网页放大状态下执行适配。当前scrcpy 1.19-ws8会缓存屏幕几何信息，因此适配/恢复后会受控重启云手机串流进程并自动刷新H5连接，其他已打开观看页需要刷新。修改尺寸可能使Android应用重新布局或重建；固定比例应用仍可能自行留边。

## 验证

本地：`node scripts/test-display-profiles.js`、`node scripts/test-display-readiness.js`、`node scripts/test-touch-input.js`，以及生产前后端构建。

手机：适配后检查完整桌面和正常文字比例；打开应用，点击四角附近按钮，滑动列表、测试双指及输入法；刷新网页确认保留；展开/收起Safari工具栏确认没有反复重排；最后验证恢复原始屏幕。桌面浏览器按402×639模拟不等同于iPhone Safari实机验收。

## 故障与恢复

新画面未就绪时保持触控暂停，菜单会提供 **重新连接画面**。请求中断不代表修改未执行，界面会重新读取Android实际配置再决定是否恢复触控。服务升级期间旧页面可能断流，刷新即可重新连接。

画面校验同时支持 MSE 的 video 和 WebCodecs 的 Canvas。以服务器原始 `ScreenInfo` 核对 Android 逻辑尺寸，以实际呈现的帧核对编码尺寸；WebCodecs 为 Canvas 生成的尺寸不覆盖原始元数据。静止桌面只要已呈现帧即可恢复触控。诊断菜单版本为 `iPhone-v7-20261026`；触控层的 `data-touch-state` 标记 `suspended` / `ready`，便于只读排障。

Safari 不提供普通 `MediaSource` 时，旧 `player=mse` 链接会在支持 WebCodecs 的浏览器自动改用它并更新地址。也可使用 `iphone-touch.html` 自动选择播放器；不要把桌面 MSE 验证等同于手机 Canvas 播放器验证。

管理员可先备份上述配置目录，再通过本页面“恢复原始屏幕”恢复。不要仅删除JSON文件：这不会自动恢复Android覆盖值。若确认首次适配前没有尺寸/DPI覆盖，也可在停止服务或移走该设备配置后，通过ADB执行 `wm size reset` / `wm density reset`；否则应还原JSON中 `original` 记录的具体覆盖值。

SilkPulse沿用现有可选开关；本功能不改变其默认关闭设置。排障可读取设备日志、网络与错误，远程执行仅使用只读表达式。
